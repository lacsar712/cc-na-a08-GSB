# 航标灯光巡检台

登记航标实测光强、方位偏差、每分钟闪次与周期秒，服务端当场给出合格、周期不合或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

周期秒须在 2 至 10 之间才放行。登记或改正时若因周期触雷，会在**周期门禁册**另存一行当时的闪次、周期秒、判词与说明原文；改正实测后旧册行不动。


## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 用充足亮度、接近零度的偏角、周期 1 秒登记一条：详情结论为「周期不合」，说明写明秒数；顶栏进入周期门禁册，可看到该条闪次与 1 秒。
4. 在详情页改正这条的周期为 2 至 10 之间：详情变为合格，门禁册旧册行仍写 1 秒。
5. 若周期与光强（或方位）同时触雷，结论为不合格，说明中两件事都保留。
6. 换 watch 登录，顶栏没有登记、改正与周期门禁册入口；直接提交这些地址会拒绝（403）。
